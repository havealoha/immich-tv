# Immich TV Marketing Site

Standalone marketing site for Immich TV.

## Stack

- Vite
- React
- TypeScript
- Firebase Hosting

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## Firebase deployment

1. Copy `.firebaserc.example` to `.firebaserc`
2. Replace the Firebase project id
3. Run:

```bash
npm run firebase:deploy
```
